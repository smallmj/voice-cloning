## 1. VibeVoice（微软）

### 1.1 型号、参数量、发布方、最新版本与日期

VibeVoice 已从"一个 TTS 模型"演变为**语音模型家族**（TTS + ASR）：

| 型号 | 参数量 | 发布日期 | 权重状态（2026-09-16） |
|---|---|---|---|
| VibeVoice-TTS **1.5B** | 1.5B | 2025-08-25 | ✅ 公开（HF `microsoft/VibeVoice-1.5B`） |
| VibeVoice-**Large**（7B） | ~7B | 2025-08-26 | ❌ **官方权重已下架**（HF API 返回 `Invalid username or password`，官方文档表格标 "Disabled"） |
| VibeVoice-**Realtime-0.5B** | 0.5B | 2025-12-03 | ✅ 公开，MIT |
| VibeVoice-ASR | — | 2026-01-21 | ✅ 公开，MIT（50+ 语言，60 分钟单次） |
| VibeVoice-ASR-BitNet | — | 2026-07-23 | ✅ 公开，MIT（边缘 CPU 推理） |
| VibeVoice-ASR-Streaming 1.5B/7B | — | 2026-09-03 | ✅ 公开，MIT（10 语言流式转写） |

发布方：Microsoft。VibeVoice-TTS 论文被 **ICLR 2026 接收为 Oral**（`openreview.net/pdf?id=FihSkzyxdv`）。

### 1.2 🔴 2025-2026 年"仓库被删除"事件的真实经过（重点）

**这不是一次简单的删库，而是一次"删代码但保留权重"的分裂处置。** 按时间线还原：

1. **2025-08-25** — 微软开源 VibeVoice-TTS，长音频多说话人 TTS，最长 90 分钟、最多 4 个说话人。
2. **2025-08-26** — 补发 VibeVoice-7B（Large）权重。
3. **2025-09-04** — GitHub 仓库**被整体移除**，权重页面也一度消失。HF 讨论区当时出现帖子标题："The github repo is deleted"（`huggingface.co/microsoft/VibeVoice-1.5B/discussions/30`）。第三方媒体（windowsnews.ai）描述为"发布仅 11 天后因滥用而下架"。
4. **2025-09-05** — 微软**恢复了仓库但移除了 TTS 代码**。官方 README 原文（2025-09-05 条目）：

   > "After release, we discovered instances where the tool was used in ways inconsistent with the stated intent. Since responsible use of AI is one of Microsoft's guiding principles, **we have removed the VibeVoice-TTS code from this repository.**"

5. 官方 `docs/vibevoice-tts.md` 中 "Installation and Usage" 一节现仅一行：

   > **"Disabled due to widespread misuse."**

6. **2025-12-03** 起，微软以"只发不克隆"的路线回归：开源 **VibeVoice-Realtime-0.5B**（流式文本输入），2026-01-21 开源 **VibeVoice-ASR**，2026-09-03 开源 ASR-Streaming。仓库最后一次提交 **2026-09-03**，**54,325 stars**（GitHub 抓取）。

**当前实际状态（务必区分）：**

- **代码**：官方仓库中 VibeVoice-TTS 的推理/训练代码**永久不可用**（只有文档留下）。
- **1.5B 权重**：**仍然公开可下载**。`microsoft/VibeVoice-1.5B` 在 HF 上 `gated: false, disabled: false`，**下载量 425,491**、点赞 2,484、最后更新 2026-01-22。MIT。
- **7B（Large）权重**：官方仓库已不可访问；官方文档直接标注 "Disabled"。
- **社区已完整接盘**：
  - `vibevoice-community/VibeVoice`（社区 fork，明确写明"Following the removal of the official VibeVoice repository, this fork serves to preserve the codebase"）——**恢复了 TTS-1.5B 推理代码**，并新增 voice cloning、LoRA 微调流程、扩展 WebUI、测试套件。
  - `davidamacey/VibeVoice`——同样恢复 TTS-1.5B 推理代码 + voice cloning + LoRA + WebUI。
  - HF 上存在独立组织 `vibevoice/`，重新上传了 **VibeVoice-7B**（23,105 下载、213 点赞、**MIT**、未被 disabled）、VibeVoice-1.5B（56,953 下载）、`-hf` Transformers 版本、VibeVoice-Large、Audio-Tokenizer、Semantic-Tokenizer、Processor。
  - **2026-08-27：VibeVoice 正式进入 HuggingFace Transformers**（PR #40546），官方社区 fork 提供 1.5B 与 7B 的 `-hf` 权重，支持 batch 推理与 `torch.compile`。
  - GGUF：`gguf-org/vibevoice-gguf`（48 赞）、`cstr/vibevoice-1.5b-GGUF`、`cstr/vibevoice-realtime-0.5b-GGUF`、`wsbagnsv1/VibeVoice-Large-pt-gguf`。

**结论**：想要 VibeVoice-TTS，今天必须走"社区 fork 代码 + HF 上 1.5B/7B 权重"的组合。7B 的官方来源已死，但社区镜像与 MLX/GGUF 转制活跃。

### 1.3 能力

- **零样本克隆**：✅（1.5B/7B 均支持；社区 fork 显式增加了 voice cloning 与 LoRA 微调）
- **few-shot 微调**：✅（社区 fork 提供 LoRA 微调流程 `FINETUNING.md`；官方无）
- **voice design**：❌ 未提供（靠参考音频）
- **中文质量**：⚠️ **官方自认不稳定**。`docs/vibevoice-tts.md` 的 Tips 原文建议：
  - 中文文本**改用英文标点**，最好只用逗号和句号；
  - **使用 Large（7B）变体，稳定得多**；
  - 若语速过快，把文本切成多个 turn 并复用同一 speaker 标签。
  - Reddit r/LocalLLaMA 社区反馈："1.5B 用不到 10GB 显存"，"7B 版本问题很多，会随机换音色"。
- **多语言**：1.5B 官方标注 English / Chinese 及其他；**Realtime-0.5B 在 2025-12-16 追加实验性音色，覆盖 9 种语言**（DE、FR、IT、JA、KO、NL、PL、PT、ES）+ 11 种英文风格音色。
- **情感/方言控制**：部分支持（官方致谢 HF 用户 PsiPi 分享的情感控制技巧，见 discussion12）；方言 ❌ 未核实。
- **流式**：✅ VibeVoice-Realtime-0.5B 支持**流式文本输入**（LLM 首个 token 即可开口）；ASR 侧亦支持 chunk 流式。
- **长文本/多人对话**：✅✅ 这是它的核心卖点——**单次最长 ~90 分钟、最多 4 个说话人**（1.5B 上下文 64K）；Large 32K / ~45 分钟。
- **语音转换（VC）**：❌ 未提供。

### 1.4 硬件

| 精度 | VibeVoice-1.5B | VibeVoice-7B |
|---|---|---|
| **FP16** | 峰值 6.7 GB；RTF **1.85×** | 峰值 21.7 GB；RTF **0.53×** |
| **INT8** | 峰值 5.4 GB；RTF **2.63×** | 峰值 14.9 GB；RTF **1.06×** |
| **INT4** | 峰值 4.6 GB；RTF **2.72×** | 峰值 11.2 GB；RTF **1.16×** |
| **INT4（no-semantic）** | 峰值 **3.8 GB**；RTF **4.30×** | 峰值 **9.8 GB**；RTF **1.37×** |

> 以上为 `gafiatulin/vibevoice-mlx` 在 **Apple M4 Max / 64 GB** 上、voice cloning 模式、~30 秒输出音频的官方基准（RTF = 音频时长 ÷ 生成耗时，>1 表示快于实时）。

- **显存（CUDA）**：社区报告 1.5B FP16 约 <10 GB；第三方（Spheron）测算 Realtime-0.5B FP16 约 2 GB。
- **CPU 推理**：TTS 侧未核实官方 CPU 路径。但 **VibeVoice-ASR-BitNet（2026-07-23）明确支持边缘 CPU**：异构量化（I8_S + I2_S）把模型从 4.62 GB 压到 **1.58 GB**，在 **3+ 线程上 RTF < 1**，无需 GPU。
- **🍎 Apple Silicon MPS 支持：✅ 是（走 MLX 路线，不走 PyTorch MPS）**
  - `gafiatulin/vibevoice-mlx`：**纯 MLX，推理期无 PyTorch 依赖**，支持 1.5B/7B、零样本克隆、多参考音色、音色嵌入保存（`.safetensors`）、`--quantize 8`/int4。上面的 M4 Max 表格就是它给的。
  - `appautomaton/vibevoice-mlx`（HF，Apache-2.0 标注）：VibeVoice Large 的 MLX int8 转换，"Pure MLX, runs locally on Apple Silicon"，支持多说话人对话（`Speaker 0:` / `Speaker 1:` 标签）与克隆。
  - 注意：`microsoft/VibeVoice-1.5B` 的 `library_name` 是 `transformers`，**PyTorch MPS 官方路径未核实**；Mac 上应优先 MLX 或 GGUF。
- **磁盘占用**：HF 上 1.5B 权重为 3 个 safetensors 分片，共约 5.41 GB（HF 文件列表）。
- **推理速度（CUDA）**：未核实官方 RTF。

### 1.5 许可证（精确）

- **代码 + 权重：MIT License**（GitHub 仓库徽章 + HF `cardData.license = "mit"`，且 `license:mit` 在 tags 中）。
- **额外条款（重要矛盾点）**：1.5B 模型卡正文明确写有免责声明：
  > "We do not recommend using VibeVoice in commercial or real-world applications without further testing and development. This model is intended for research and development purposes only."
  
  即：**MIT 在法律上允许商用，但微软在模型卡上明确劝阻商用**。对商业桌面软件而言，这是"法律可行、道义/风险存疑"的灰色地带，建议提请法务确认，或直接选 Qwen3-TTS/OmniVoice。
- **VibeVoice-ASR / Realtime-0.5B**：同为 MIT。

### 1.6 主观质量

- **ICLR 2026 Oral** 接收；论文报告在长音频多说话人任务上 SOTA，并给出 MOS preference 图。
- 无官方 TTS Arena / seed-tts-eval 排名（官方评测集中在长音频多说话人场景）。
- 社区口碑两极：1.5B 因"能生成 90 分钟播客"广受欢迎（425k 下载、2.4k 赞）；7B 因音色漂移被诟病。

### 1.7 工程可用性

- **官方 pip 包**：❌（TTS 代码已禁用）。ASR 侧有 HF Transformers 集成。
- **Transformers 支持**：✅（2026-08-27 起，走 `vibevoice/*-hf` 权重；realtime 模型 PR #42781 待合并）。
- **vLLM**：✅ 仅 ASR（`docs/vibevoice-vllm-asr.md`、`vllm-asr-streaming.md`）。TTS ❌。
- **GGUF / llama.cpp**：✅ 社区 GGUF 存在（`cstr/vibevoice-1.5b-GGUF`、`cstr/vibevoice-realtime-0.5b-GGUF`、`wsbagnsv1/VibeVoice-Large-pt-gguf`、`gguf-org/vibevoice-gguf`）。官方无。
- **MLX**：✅ 见上。
- **API 服务器**：❌ 官方无。社区 fork 提供 Gradio/WebUI。
- **活跃度**：仓库 54,325 stars，最后提交 **2026-09-03**，184 open issues（其中大部分为 TTS 下架遗留）。

### 1.8 已知坑

1. **TTS 代码官方永久禁用**，必须依赖社区 fork（供应链风险：非官方组织维护）。
2. **7B/Large 官方权重已删**，只剩社区镜像。
3. **中文不稳定**，官方自己建议用英文标点、上 7B、切分文本。
4. **7B 音色随机漂移**（社区报告）。
5. MIT 与"仅研究用途"声明冲突。
6. 7B FP16 需 ~21.7 GB（Mac）/ 显存压力大；Mac 上必须量化到 int4 才实用。

## 2. Zonos（Zyphra）

### 2.1 型号与版本

- **Zonos-v0.1**（beta）：2025-02-06/07 发布。两个变体，各 **1.6B**：
  - `Zyphra/Zonos-v0.1-transformer` — 169,903 下载 / 435 赞
  - `Zyphra/Zonos-v0.1-hybrid`（SSM+Transformer 混合）— 1,270 下载 / **1,108 赞**
  - 另有 `Zyphra/Zonos-v0.1-speaker-embedding`
- **ZONOS2**：**2026-06-11 发布**（`Zyphra/ZONOS2`，146 赞 / 702 下载）。训练数据 600 万+ 小时，**MoE 骨干**，低延迟高保真克隆。官方独立仓库 `Zyphra/ZONOS2`（**311 stars**，最后提交 2026-07-06）。配套 `Zyphra/ZONOS2-GGUF`（7,858 下载）。

### 2.2 能力

**Zonos-v0.1：**
- 零样本克隆：✅ 10–30 秒参考音频
- audio prefix 条件：✅（可诱发耳语等 speaker embedding 难以复现的行为）
- 多语言：**English, Japanese, Chinese, French, German**（5 种）
- 情感控制：✅ **happiness / anger / sadness / fear** 等；另有语速、音高变化、最高频率、音质精细控制
- 原生输出：**44 kHz**
- 流式：❌ 未核实
- 长文本/多人对话：❌（单说话人）
- voice design：❌

**ZONOS2：**
- 多语言三层分级：
  - Tier 1：English、Mandarin Chinese、Japanese
  - Tier 2：Korean, Russian, Italian, Portuguese, French, Spanish, Vietnamese, German, Hebrew, Dutch
  - Tier 3：Swedish, Hindi, Tamil, Telugu, Thai, Norwegian, Bengali, Tagalog, Arabic, Danish, Indonesian, Polish, Ukrainian, Romanian, Finnish, Hungarian, Lithuanian, Estonian, Slovak, Croatian, Latvian
- 高保真自然克隆（核心卖点）；MoE 低延迟
- 使用 nemo TN 归一化 UTF-8 bytes + ECAPA-TDNN embedding → DAC tokens

### 2.3 硬件

**Zonos-v0.1（官方 System requirements）：**
- OS：Linux（推荐 Ubuntu 22.04/24.04）、**macOS**
- GPU：**6 GB+ VRAM**；**hybrid 变体额外要求 3000 系或更新 NVIDIA GPU**（依赖 `mamba_ssm`）
- CPU：可跑，"provided there is enough free RAM"，但明显慢于 GPU，"likely won't be sufficient for interactive use"
- 速度：**RTF ~2× on RTX 4090**（即 1 秒算力生成 2 秒音频）
- 系统依赖：`espeak-ng`（macOS: `brew install espeak-ng`）

**ZONOS2：**
- 官方快速上手明确写：**"Platform Support: Linux only (x86_64). Requires NVIDIA GPU with CUDA toolkit"**
- 本地推理服务器基于 **Mini-SGLang**，默认端口 1919，提供 `POST /tts/generate`

**🍎 Apple Silicon MPS 支持：Zonos-v0.1 = ⚠️ 部分/事实上不可用；ZONOS2 = ❌ 官方不支持**
- `Zyphra/Zonos` **Issue #1 "Apple Silicon Support?"**（2025-02-10 创建，长期 open）：作者指出 `mamba_ssm` 库**尚未支持 Apple Silicon**。
- **Issue #185 "MPS Support"**（2025-03-10，open）：原文注释 `# MPS breaks for whatever reason. Uncomment when it's working.`（源码中 MPS 分支被注释掉）。
- **PR #190 "Add MPS support"**（2025-03-11 创建，2025-04-14 最后更新，作者 12v）：**至今 open、未合并**。PR 说明两个阻塞点：① `torch.compile` 不支持 MPS（PyTorch 论坛确认）；② 第二个问题未解决。
- **ZONOS2 官方只支持 Linux + NVIDIA**，Mac 只能走社区转制：`Zyphra/ZONOS2-GGUF`（Zyphra 自己发的 GGUF）、`mlx-community/Zyphra-ZONOS2`（2026-06-13）、`shraey/zonos2-mlx`。**这些社区路线在 Mac 上的实际可用性未核实。**
- Zonos v0.1 也有 GGUF：`cstr/zonos-v0.1-transformer-GGUF`（791 下载）、`Zyphra/ZONOS1-GGUF`（180 下载）；MLX：`mlx-community/Zonos-v0.1-transformer-bf16`（仅 37 下载）。

### 2.4 许可证

- **Zonos-v0.1：Apache License 2.0**，代码与权重均是（GitHub `LICENSE` 文件正文确认为 Apache 2.0；HF `cardData.license = "apache-2.0"`）。官方博客原文："We are releasing our 1.6B transformer and 1.6B hybrid **under an Apache 2.0 license**."
- **ZONOS2：Apache License 2.0**（HF cardData 确认）。
- **额外条款**：未在 v0.1/ZONOS2 许可证文件中发现可接受使用政策附加条款（Apache 2.0 标准文本）。**商业使用、再分发、打包进商业桌面 App：✅ 允许。**
- ⚠️ 提醒：Apache 2.0 不授予商标权，且需保留 NOTICE/版权声明。

### 2.5 主观质量

- Zonos-v0.1：官方宣称"expressiveness and quality on par with—or even surpassing—top TTS providers"，训练数据 20 万+ 小时。**无 TTS Arena / seed-tts-eval 可引用的具体数字 → 未核实。**

## 12. 对"声音复刻软件（Mac 桌面 App）"的选型建议

基于本批调研的一手证据，按场景推荐：

1. **首选：Qwen3-TTS（0.6B/1.7B）**
   - Apache-2.0 无附加条款，商用最干净
   - Seed-TTS test-zh WER 0.77 / test-en 1.24，同规模最优
   - 3 秒克隆 + voice design + 流式 97ms + 10 语言 + 方言音色
   - **Mac 路线成熟度最高**：mlx-audio（7.9k stars）+ qwentts.cpp（Metal + GGUF + OpenAI 兼容 server）+ 现成的原生 macOS App（QwenVoice）
   
2. **最轻量/最多语言：OmniVoice（612M）**
   - Apache-2.0，官方 `device_map="mps"`
   - 600+ 语言、3–10 秒克隆、voice design（含中文方言）、音色 prompt 可持久化（.pt）
   - PyPI 官方包 + 三个 CLI 入口
   - RTF 0.0367（H100 CUDA graph batch1）——极快

3. **最高音质/方言：VoxCPM2（2B）**
   - Apache-2.0，官方 MPS + 48kHz 工作室级输出
   - 30 语言 + 9 种中文方言（四川/粤语/吴语/东北/河南/陕西/山东/天津/闽南）
   - Mac 实测 RTF 1.76（M4 Pro Q8_0 GGUF/Metal）

4. **多人对话/播客：MOSS-TTSD v1.0 或 MOSS-TTS-Nano**
   - Apache-2.0，1–5 人、60 分钟、20 语言
   - MLX int8 + llama.cpp GGUF 双路线；8B 可进 8GB
   - 极轻量替代：MOSS-TTS-Nano（0.1B，MacBook Air M4 单核 CPU）

5. **避开**：Llasa（NC）、LLaMA-Omni 2（NC）、Step-Audio/Kimi-Audio（CUDA 绑定 + 定位不符）、VibeVoice TTS（代码下架 + 商用劝阻声明）
