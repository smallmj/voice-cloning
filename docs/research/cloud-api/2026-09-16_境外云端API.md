## 1. 核心结论速览

| 维度 | 结论 |
|---|---|
| **综合效果第一梯队** | Cartesia Sonic 3.6 (Elo 1277) > Inworld Realtime TTS-2 (1243) ≈ Speechify Simba 3.2 (1238) —— **前三名差距 <40 Elo，听感差异很小** |
| **中文可用性最好** | MiniMax Speech（国内版）、Fish Audio S2.1 Pro、Azure Speech（含中国区）、ElevenLabs Multilingual v2、Boson AI Higgs TTS 3、火山引擎豆包语音 |
| **中文明确不可用** | OpenAI TTS（能读但不出彩）、Hume Octave、Rime AI、Deepgram Aura、Speechify Simba 3.2（纯英文）、Groq Orpheus、Sarvam Bulbul v3 |
| **对第三方软件代理调用最友好** | OpenAI（明文允许集成进 Customer Application）、Fish Audio（主动招揽集成合作）、MiniMax、Inworld、Speechify、Azure/AWS/Google（标准云 ToS） |
| **明确受限** | **ElevenLabs**（禁令+需 OEM 协议）、**Deepgram**（ToS 禁 resell，non-sublicensable）、**PlayHT**（API key 不得嵌入客户端代码）、**Murf**（有商用权但无转售权）、**Smallest.ai**（不得创造衍生作品）、**Cartesia**（ToS 与定价页存在张力） |
| **中国大陆直连** | Azure 中国区 ✅、AWS 中国宁夏区 ✅、MiniMax 国内版 ✅、Fish Audio 🟡基本可用、SiliconFlow/火山/阿里 ✅；其余**全部需代理** |

### ⚠️ 三个必须知道的"坑"

1. **LMNT 已停服**：官网与文档页均显示 "LMNT has shut down / Our speech generation journey has come to an end"。其 SEO 描述仍残留 "31 languages / 5 秒克隆" 的旧文案，容易被搜索结果误读为在运营状态 —— **不要选型**。
2. **F5-TTS 权重非商用**：代码是 MIT，但**官方预训练权重是 CC-BY-NC-4.0**，极易被误判为可商用。
3. **XTTS-v2（Coqui）已无法合法商用**：CPML 非商用许可，且 Coqui 已于 2024-01 关停，**商用授权无处购买**。

### 6.3 合规风险事件

> **Lovo v. Lehrman 集体诉讼（重要供应商风险信号）**
>
> 配音演员 **Paul Lehrman 与 Linnea Sage** 在纽约南区法院（**24-CV-3770 (JPO)**）对 **Lovo, Inc.** 提起拟议集体诉讼，指控 Lovo 使用 AI **未经授权合成并销售其声音克隆**。
>
> **2025-07-10**，**J. Paul Oetken 法官**作出 **60 页裁定**：**驳回部分诉请，但允许部分诉请继续**（涉及合同法、版权法与州法上的声音保护）。路透社、BBC、Skadden 等均有报道。
>
> **对选型的意义**：**供应商侧的声音授权链路存在公开法律争议**。若你的第三方软件依赖某家的音色库，需评估该库音色的授权来源是否干净。
>
> 来源：[法院裁定原文 PDF](https://www.nysd.uscourts.gov/sites/default/files/2025-07/Lovo%20v%20Lehrman.pdf) · [Reuters](https://www.reuters.com/legal/litigation/voice-actors-can-pursue-some-claims-over-ai-voiceovers-us-court-says-2025-07-10/) · [BBC](https://www.bbc.com/news/articles/cedgzj8z1wjo) · [Law.com](https://www.law.com/newyorklawjournal/2025/07/11/actors-may-continue-lawsuit-against-lovo-over-ai-voice-clones-judge-rules/) · [Skadden 分析](https://www.skadden.com/insights/publications/2025/07/new-york-court-tackles-the-legality-of-ai-voice-cloning)

#### ⚠️ 中国大陆合规提醒（比网络更关键）

**《互联网信息服务深度合成管理规定》**（网信办，**2022-12-11 公布，2023-01-10 施行**）：

- 明确规定「**合成人声、仿声等语音生成或者显著改变个人身份**」属**深度合成技术**；
- **深度合成服务提供者**须落实：信息安全主体责任、**算法机制机理审核**、科技伦理审查、信息发布审核、数据安全、个人信息保护、反电信网络诈骗、应急处置等管理制度；
- **应用程序分发平台（应用商店）** 须核验深度合成类 App 的**安全评估、备案**情况；违反者可**不予上架、警示、暂停服务或下架**。

👉 **这意味着：把声音复刻做成中国大陆可下载的桌面/移动软件并公开分发，很可能被认定为「深度合成服务提供者」，需要算法备案 + 安全评估。这是比"选哪家 API"更大的合规门槛。**

**其他合规义务**：
- **生成内容显式标识**（多家厂商本身也要求披露：OpenAI 强制 AI 披露、Cartesia 有 Disclosure Requirements）
- **声音权 / 肖像权 / 版权授权**：克隆他人声音需取得授权；Fish Audio、PlayAI 的 ToS 都把这一责任推给集成方

来源：[深度合成管理规定](https://www.cac.gov.cn/2022-12/11/c_1672221949354811.htm) · [答记者问](https://www.cac.gov.cn/2022-12/11/c_1672221949570926.htm) · [Cartesia 披露要求](https://www.cartesia.ai/legal/disclosure-requirements)

## 8. 最终结论：针对「中文用户的第三方桌面软件」

### 8.1 若目标用户主要说中文

**可用（推荐）—— 按优先级：**

1. **火山引擎豆包语音合成 / 声音复刻 2.0**（国内）— 5 秒克隆、相似度 97.5%、首包 <300ms、直连
2. **MiniMax Speech 2.8 国内版** — 中文母语级、国内直连、克隆便宜
3. **阿里云百炼 CosyVoice v3-plus** — 中文第一梯队、5–20s 克隆、2 元/万字符
4. **Azure Speech 中国区** — 企业级 SLA + 中文原生音色 + 首包 ~120ms
5. **Fish Audio S2.1 Pro** — 中文口碑好、克隆最快；**注意字节计费 ×3**
6. **ElevenLabs Multilingual v2** — 中文 MOS 最高，但 $100/1M 字符 + 需代理 + 转售受限
7. **Boson AI Higgs TTS 3** — 中英同价 + 100+ 语言 + OpenAI 兼容
8. **自托管 CosyVoice 2 / Qwen3-TTS / Chatterbox Multilingual** — Apache-2.0 / MIT，中文强、商用干净、无网络限制

**明确不可用（排除）：**

| 服务 | 原因 |
|---|---|
| **Hume AI Octave** | 11 语言无中文 |
| **Rime AI** | 语言矩阵无 zh |
| **Deepgram Aura** | 7 语无中文 + 无克隆能力 |
| **Speechify Simba 3.2** | 纯英文，非英语返回 400 |
| **Groq Orpheus** | 仅英语 + 沙特阿拉伯语 |
| **Sarvam Bulbul v3** | 仅 10 种印度语言 + 英语 |
| **LMNT** | 已停服 |
| **OpenAI TTS** | 能读中文但质量不出彩，且中国大陆不可用 |
| **Deepgram / Rime / Hume / Sarvam** | 中文化直接出局（有据可查） |

### 8.2 对「第三方软件代理调用」有明确限制的服务

| 服务 | 限制 | 可行路径 |
|---|---|---|
| 🔴 **ElevenLabs** | Prohibited Use Policy 明文禁止未授权转售/再许可 | 签 **OEM 协议**，或**终端用户自带 key** |
| 🔴 **Deepgram** | ToS 明文禁止 resell / redistribute；MSA non-sublicensable | 加入 **Partner Program** 获得白标授权 |
| 🔴 **PlayHT** | **API key 不得分享、不得嵌入客户端代码** | **必须自建后端代理**（不能把 key 打进桌面客户端） |
| 🔴 **Murf** | ToS 5.1 **明确无转售权** | 需单独授权 |
| 🟡 **Cartesia** | ToS 与定价页存在张力（个人非商用 vs Pro+ 含商用许可） | 只用 Pro 及以上，白标前**书面确认** |
| 🟡 **Smallest.ai** | MSA 禁止超授权范围使用与创造衍生作品 | 需单独授权 |
| 🟡 **Amazon Polly Brand Voice / Azure CNV / Google Instant Custom Voice** | 定制音色需申请/审核/合约 | 走企业合约 |
| 🟡 **PlayAI / LOVO** | 音色合法性责任压在集成方；LOVO 有在诉集体诉讼 | 建立自己的音色授权审核流程 |
| 🟢 **OpenAI / Fish Audio / MiniMax / Inworld / Speechify / 云厂商 / 托管平台** | 明确允许集成进自己的产品 | 直接使用，注意披露义务 |

### 8.3 中国大陆网络直连的可行性

- **✅ 可以直连：** Azure 中国区、AWS 中国宁夏区、MiniMax 国内版、阿里云百炼、火山引擎、SiliconFlow 中国站、Fish Audio（基本可用）
- **❌ 必须代理：** ElevenLabs、Cartesia、Inworld、Speechify、Deepgram、Hume、Resemble、PlayAI、Rime、Smallest、Sarvam、Boson、Murf、LOVO、Neuphonic、Unreal、Groq、Together、Replicate、fal、Google Cloud
- **❌ 禁止使用（有封号风险）：** **OpenAI** —— 官方明文「在不支持地区访问或提供访问可能导致账号被封禁或暂停」
- **代理的额外代价：** 首包延迟增加（ElevenLabs 从 ~75ms 推理延迟变成实测 450ms+）、连接稳定性下降、付款需海外卡
- **⚠️ 合规代价（比网络更关键）：** 《互联网信息服务深度合成管理规定》要求深度合成服务提供者落实**算法机制机理审核与备案**；**应用商店上架深度合成类 App 需核验安全评估与备案**。「合成人声、仿声」被明确列举

### 8.4 落地建议（务实路线）

```
【面向中国大陆用户】
├─ 主力：火山引擎豆包语音（5s 克隆 / 97.5% 相似度 / 首包 <300ms / 直连）

├─ 备选：阿里云百炼 CosyVoice v3-plus（2 元/万字符 / 5–20s 克隆）
├─ 企业级 / 要 SLA：Azure Speech 中国区（首包 ~120ms）
└─ 自托管兜底：CosyVoice 2 / Qwen3-TTS / Chatterbox Multilingual（Apache-2.0 / MIT）

【面向海外用户】
├─ 效果优先：Cartesia Sonic 3.6（榜单 #1，Elo 1,277）
├─ 综合最优：Inworld Realtime TTS-2（榜单 #2 + OpenAI 兼容 + 商用许可明确）
├─ 中文 + 集成友好：Fish Audio S2.1 Pro（官方招揽集成合作）
├─ 中英同价：Boson AI Higgs TTS 3（$15/1M，OpenAI 兼容）
└─ 成本优先：Speechify Simba 3.2（英文场景 $6/1M）

【规避转售风险】
└─ 自托管开源：Chatterbox（MIT）/ CosyVoice 2 / Qwen3-TTS（Apache-2.0）
   避开：F5-TTS 权重（NC）、XTTS-v2（CPML 且已停售）、IndexTTS 2（需联系 bilibili）

【合规底线】
├─ 中国大陆分发 → 评估「深度合成服务提供者」认定 → 算法备案 + 安全评估
```
