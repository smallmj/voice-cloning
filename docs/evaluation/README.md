# 评测记录（issue #16）

这里是**本产品自己的评测证据**——任何公开榜单都抄不到的部分。固化数据
（`sidecar/voiceclone_sidecar/data/capability_matrix.json`）驱动界面；
本目录存放人工执行与人工判读的记录。

## 文件

- [`2026-09-18_能力矩阵与听感记录.md`](./2026-09-18_能力矩阵与听感记录.md)：
  主记录。RTX 3090 RTF/峰值显存回填表、真人盲听结论表、
  「未核实 → 已核实 / 仍未知」逐条台账。

## 方法约定

- **中文回归集**：固定 17 条，五类难例（数字 / 日期 / 金额 / 中英混读 / 多音字），
  内置于 sidecar（`voiceclone_sidecar/regression.py`）。所有引擎跑同一组文本，
  文本照常过归一化层（ADR-0008）。
- **运行方式**：界面「能力矩阵」区点「运行中文回归集」，或
  `POST /regression/run`。后台逐条生成，结果存于本地回归索引，
  `GET /capability-matrix` 自动合入最新一次已完成会话。
- **RTF 口径**：音频时长 ÷ 端到端墙钟（含引擎加载与归一化），<1 = 快于实时。
  会话里同时记录纯音频时长与墙钟，便于事后复核口径。
- **峰值显存**：仅本地 CUDA 引擎采样（`nvidia-smi` 周期采样，基线增量）；
  Mac 统一内存机型记录的是峰值内存，矩阵里用 `peak_kind` 区分。
  无 GPU 环境安静地留空——不编造 0。
- **ASR 可懂度**：可选（`asr_check: true`）。用本地转写引擎回读每条输出，
  与人工校对的目标读音文本算字符错误率（CER）。ASR 是**可懂度**证据，
  永远不是听感证据。
- **主观听感**：只承认盲听。复用 issue #10 的盲听对比（同音色同文本、
  LUFS -16 归一化、盲标签、5 分制），结论记入主记录的听感表。
  ADR-0009：偏好画像只给人看，不参与任何路由。

## 诚实原则

矩阵里的每个事实带验证等级：`measured`（本项目真机实测）/ `verified`
（一手来源核实）/ `vendor`（厂商口径）/ `unverified`（调研时未核实，
结论为**仍未知**）/ `unknown`（无从核实）。**等级只能由新证据升级，
不能由愿望升级**——RTX 3090 没跑实测之前，那一格就写着「待测」。
