## 1. Rime AI（rime.ai）

- **产品/模型**：`coda`（旗舰，替代旧 Mist 作为新应用默认）、`arcana` v3（企业向）、`mistv3`、Mist v2。API 名称：Rime API（`docs.rime.ai`）；含 streaming HTTP 与 WebSocket 端点（`/api-reference/mistv3/http`、`/api-reference/arcana/http`）。认证：`Authorization: Bearer YOUR_API_KEY`。
- **语言**：文档语言矩阵按模型列出——**Coda**：英/阿/法/德/印地/日/葡/西（8 种）；**Mist v3**：英/法/德/西（4 种）；Arcana v3 宣称「10+ 语言 code-switching」。**中文（zh）未出现在任何 Rime 官方语言表中** → 中文支持：❌（或至少未核实）。
- **能力**：即时自定义声音克隆（instant custom voice cloning，全产品线）；企业声音克隆（Enterprise voice cloning，需 Growth/Enterprise 档）；word-level timestamps；Arcana v3 支持 100+ 并发/机、on-prem。**内联发音控制（inline pronunciation control）是 Mist v3 相对 Mist v2 唯一未继承的功能**（即 Mist v3 无 IPA 式内联发音控制）。
- **克隆参考音频**：企业克隆建议 **30–60 分钟干净一致录音** 作基础克隆；**2–5 小时或更多效果最好**。即时克隆的具体秒数要求未核实。同意/授权：ToS 要求客户自行保证对 Input 拥有全部权利、许可与同意（`rime.ai/services-agreement`）。
- **定价**（`rime.ai/pricing` + 新定价公告）：
  - 免费：~800 分钟（约 800k 字符），无需信用卡。

  - 新定价（2025-12-19 公告）：**Arcana $40/百万字符（≈$0.04/min）**、**Mist $30/百万字符（≈$0.03/min）**；Starter 档 20 并发 TTS。
  - Growth/Enterprise：不限并发 TTS、SLA、专属支持、云 / on-prem / VPC 部署、大体量折扣。
  - 克隆加价：未核实（未在定价页单列）。
- **延迟**：云 API 端到端 sub-200ms；Coda 在 GPU/自托管下达 sub-100ms 模型延迟；Mist v3 是 TTFA 最低的模型。Arcana v3 宣称 120ms TTFB。

- **稳定性/限额**：并发档位见上；内容审核策略未核实；商业使用/转售：Rime ToS（`rime.ai/terms`、`rime.ai/services-agreement`）为客户-厂商式服务协议，**是否允许白标转售：未核实**。

## 2. LMNT（lmnt.com）

- **产品/API**：LMNT TTS。RESTful API，基址 `https://api.lmnt.com`。子 API：**Speech API**（文本→语音，可选 word-level timestamps）、**Speech Sessions API**（渐进式流式输入文本、边生成边返回语音）、**Voice Cloning**。
- **语言**：官方语言页列 **31 种语言、支持原生 code-switching，含 Chinese（`zh`）** ✅。API `language` 参数为 ISO 639-1 两字母码，默认自动检测（显式指定可加速）。
- **能力**：即时克隆（instant cloning）**仅需 5 秒源音频**即可生成 voice prompt；克隆会复刻音色、语速、语调、口音、呼吸、啧嘴声甚至环境噪声。是否支持文本描述式「声音设计」：未核实。发音控制（IPA/SSML）：未核实。
- **克隆参考音频**：5 秒（即时）；样本数未核实；同意/授权要求：官方文档页未明示强制验证流程 → 未核实（是否有 voice CAPTCHA：未核实）。
- **定价**（第三方汇总页，2026-05/07 抓取）：**Free 15,000 字符/月**；**Indie $10/mo（200k 字符含，超出 $0.05/1k 字符）**；**Pro $49/mo**；**Premium $199/mo**；**无限声音克隆 + 商业许可**；宣称「无并发或速率限制」。注：同一来源首段又写「$10/mo 享 500K 字符」，两处数字冲突，**以官网为准、此处标为部分未核实**。AA 的 LMNT 定价口径为 USD/1M 字符（未取到具体数值）。
- **延迟**：LMNT 主打低延迟实时（文档强调「ready to serve your traffic with low latency at scale」）；具体 TTFA 数字未核实。
- **基准**：Artificial Analysis 有 LMNT 模型页与 provider 页（含 Arena Elo），具体数值未核实。HuggingFace TTS Arena：未核实。
- **Stability/限额**：宣称无并发/速率限制（付费档）；内容审核、SLA、区域可用性未核实。
- **API 接入**：REST（+ Speech Sessions 流式）；OpenAI 兼容端点未核实；官方 SDK 未核实；输出格式未核实。
- **桌面 App 嵌入**：白标/转售条款未核实；是否要求终端用户自带 Key 未核实。

## 4. Speechify AI（SpeechifyAI / Simba，speechify.ai）

- **产品/模型**（docs.speechify.ai 模型表）：**Simba 3.2**（`simba-3.2`，英文，流式原生，推荐）、**Simba 3.0**（`simba-3.0`，英语 + 德/西(西班牙+墨西哥)/法/意/巴西葡）、**Simba Multilingual**（`simba-multilingual`，30+ 语区）、**Simba English**（`simba-english`，legacy）、Simba 1.6（legacy）。API 基址 `api.speechify.ai`（`POST /v1/voices`、`POST /v1/audio/stream`）。
- **中文支持**：**simba-3.2 与 simba-english 仅英文，传非英语 voice 返回 400**；非英语须用 `simba-3.0` 或 `simba-multilingual`；`simba-multilingual` 覆盖「30+ locale 全集」，**该全集中是否含中文未逐项取到 → 标为未核实（大概率支持）**。

- **能力**：
  - **即时声音克隆（Instant Voice Cloning）**：由**单条 ≤30 秒参考录音**构建 workspace 级 AI 音色；可上传文件或指向公开 URL，轮询就绪后用返回的 voice ID 调任意 **Falcon 2** 端点；**无需预约 studio session**（2026-09-02 文档）。
