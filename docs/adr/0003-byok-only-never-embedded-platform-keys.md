# 云端调用一律 BYOK，不内置平台密钥代调用

每个用户填自己的 API Key，密钥存进系统钥匙串（macOS Keychain / Windows Credential Manager）。应用不提供「用开发者的 Key 帮你调用」的模式，也不做账号体系。

**依据（均为条款原文，来自调研）**：火山引擎（生成数据所有权归火山 + 单终端许可 + 禁转许可）、阿里云百炼（明文「不得转售本服务及平台内模型」）、科大讯飞（明文「不得转售、转租或提供给任何其他第三方使用」）、PlayHT（明文禁止 API key 嵌入客户端代码）。而 OpenAI 明文允许集成进自己的产品。BYOK 是唯一对绝大多数厂商都成立的形态。

**副作用（正面）**：走 BYOK 时终端用户是厂商自己的客户，腾讯云要求的「对终端用户做真实身份认证」等深度合成服务提供者义务由厂商侧承担，而非本应用。这使「不做账号体系」得以成立。

**待验证假设**：上述合规解读尚未经律师确认，尤其是《互联网信息服务深度合成管理规定》对「工具」与「服务提供者」的区分。在公开在境内分发之前必须重新评估（当前决定是私下分发）。
