## 0. 先说结论：面向「商业桌面 App 内嵌」的选型速查

**许可证能直接内嵌进闭源商业桌面 App 的（代码 + 权重都放行）：**

| 模型 | 许可证 | 备注 |
|---|---|---|
| **Chatterbox 全家桶** | MIT（代码+权重，已 curl LICENSE 原文核实） | 唯一「大厂 + MIT + 强克隆 + 有中文 + 有 CPU 小模型」的组合 |
| **dots.tts** | Apache-2.0（代码+checkpoints，README 明确） | 中文最强（Seed-TTS-Eval zh WER 0.94%），但 2B 需要 5.7–7.9GB 显存 |
| **Kani-TTS（代码）** | Apache-2.0 | ⚠️ **但权重是 LFM 1.0，年营收 >$10M 需另购授权** |
| **OuteTTS（代码）** | Apache-2.0 | ⚠️ **但主力权重 1.0-1B 是 CC-BY-NC-SA-4.0，非商用** |
| **OpenVoice v2** | MIT（代码+权重，HF 卡明确） | 但不是完整 TTS，只是「音色转换器」，必须配一个基座 TTS |
| **RVC / Applio** | MIT | 但**需要逐说话人训练**，不是零样本 |
| **Muyan-TTS** | Apache-2.0 | 但**仅英文**、仓库已 16 个月未更新 |
| **Seed-VC** | GPL-3.0 | ⚠️ **传染性 copyleft：闭源商业 App 内嵌需开源你的代码**；且**已归档停止维护** |

**明确不能商用内嵌的：**

| 模型 | 许可证 | 结论 |
|---|---|---|
| **VoiceCraft** | 代码 CC BY-NC-SA 4.0 + 权重 Coqui Public Model License 1.0.0 | ❌ **双重非商用**。Coqui 原文：「This license allows only non-commercial use of a machine learning model and its outputs」 |
| **NeuTTS-Nano / NeuTTS-2E** | NeuTTS Open License 1.0 | ⚠️ 年营收 ≥ $5,000,000 USD 即超出授权（NeuTTS **Air 是 Apache-2.0**，是例外） |
| **Diff-HierVC** | CC BY-NC-SA 4.0 | ❌ 非商用 |
| **Vevo（权重）** | CC-BY-NC-4.0 | ❌ 权重非商用（Amphion 代码是 MIT） |
| **OuteTTS 1.0-1B / 0.2 / 0.3 权重** | CC-BY-NC(-SA)-4.0 | ❌ 非商用 |
| **IndexTTS2** | bilibili Model Use License | ⚠️ MAU > 1 亿 或 年营收 > 10 亿人民币需单独授权 |
| **Kani-TTS 权重** | LFM Open License 1.0 | ⚠️ 年营收 > $10M USD 需另购 |

**Apple Silicon（MPS）支持最好的**：Chatterbox（官方显式支持 + `example_for_mac.py`）、Kani-TTS（官方 MLX 权重 + `kani-mlx` 仓库）、NeuTTS（llama.cpp Metal / Apple Accelerate）、dots.tts（社区 MLX 移植，含 int4 量化）。

**MPS 最差的**：VoiceCraft（无证据，CUDA 依赖）、Muyan-TTS（vLLM CUDA-only）、Seed-VC（Mac 装的是 CPU-only torch nightly）。

### 1.2 能力

| 能力 | 结论 |
|---|---|
| 零样本克隆（TTS） | ✅ 支持，参考音频 10s 左右 |
| **音色转换（VC）** | ✅ **支持** —— 仓库内有 `src/chatterbox/vc.py`（`ChatterboxVC` 类）、`example_vc.py`、`gradio_vc_app.py`。这是很多对比文章漏掉的关键点 |

| **中文质量** | ✅ Multilingual V3 含 zh。官方 CER 评测（whisper-large-v3 转写 100 条 held-out prompt）：**中文 Language Pack（zh-cmn）CER 0.41%**，进入 sub-1% 第一梯队。基础多语言 checkpoints 的中文 CER **未核实**（博客只列了 Language Pack 的 0.41%） |

**Apple Silicon（MPS）支持：✅ 官方支持，但存在已知 bug（判定为「部分支持」）**

- **代码级证据**：`src/chatterbox/tts.py` 第 133 行 `if device in ["cpu", "mps"]: map_location = torch.device('cpu')`，第 169–175 行专门检测 `torch.backends.mps.is_available()` 并在不可用时回退 CPU 并打印原因。`vc.py` 第 64 行同样逻辑。
- **官方 Mac 示例**：仓库根目录有 **`example_for_mac.py`**，文件顶部注释 `# Detect device (Mac with M1/M2/M3/M4)`，用 `torch.load` monkey-patch 解决 MPS 加载问题。
- **README 明确写**：`device = "cuda"  # or "cpu" / "mps"`。
- **⚠️ 已知问题**：
  - Issue [#147](https://github.com/resemble-ai/chatterbox/issues/147)：M1 8GB 上 `NotImplementedError: Output channels > 65536 not supported at the MPS device`（2025-06-11）
  - Issue [#275](https://github.com/resemble-ai/chatterbox/issues/275)：「No apple support for multilingual?」——`ChatterboxMultilingualTTS.from_pretrained(device="mps")` 报 `RuntimeError: Attempting to deserialize object on a CUDA device`（2025-09-10）
- **结论**：原版/Turbo/Nano/VC 走 MPS 相对可用（Nano 110M 走 CPU 也很现实）；**多语言版走 MPS 有明确报错记录，需自行打补丁或退回 CPU**。

### 1.6 工程可用性

- ✅ **官方 pip 包**：`pip install chatterbox-tts`（0.1.7）
- **硬依赖（`pyproject.toml` 原文）**：`torch==2.6.0` / `torchaudio==2.6.0`、`transformers==5.2.0`、`diffusers==0.29.0`、`librosa==0.11.0`、`s3tokenizer`、`conformer==0.3.2`、`safetensors==0.5.3`、`spacy-pkuseg`、`pykakasi==2.3.0`、**`gradio==6.8.0`**、`pyloudnorm`、`omegaconf`、**`resemble-perth @ git+https://github.com/resemble-ai/Perth.git@master`**
  - ⚠️ **注意**：依赖里钉死了 `transformers==5.2.0` 和 `diffusers==0.29.0`，且 Perth 从 **git master** 安装——与其它 ML 库共存时容易冲突；`gradio==6.8.0` 作为硬依赖对「只想要推理」的桌面 App 是负担。
- ✅ **ONNX 路线**：官方发布 `ResembleAI/chatterbox-turbo-ONNX`（85 likes）
- ✅ **Gradio API Server**：仓库自带 `gradio_tts_app.py`、`gradio_tts_turbo_app.py`、`gradio_vc_app.py`、`multilingual_app.py`
- ✅ **FastAPI**：未核实官方提供（Gradio 为主）
- **星标 / 活跃度**：26,439 stars，最后推送 **2026-07-21**，**活跃维护中**，364 个 open issues

### 1.7 已知坑

1. **长文本幻觉 / 重复**：Issue [#424](https://github.com/resemble-ai/chatterbox/issues/424)（2026-01-03）「Turbo can only generate small bits of audio (**~350 chars**) correctly without hallucinating」
2. **V3 的 long_tail 提前触发**：Issue [#519]「`alignment_stream_analyzer` 在极低 sample 数（~60–180 / 1000 max）就强制 EOS，导致截断前 token 重复」
3. **MPS 多语言报错**（Issue #275）、**MPS 通道数限制**（Issue #147）
4. **英语偏置**：Turbo / Nano / Flash **仅英语**；只有 Multilingual 系列覆盖中文
5. **参考音频语言必须匹配**：README 明确「Ensure that the reference clip matches the specified language tag. Otherwise, language transfer outputs may inherit the accent of the reference clip's language」——需配 `cfg_weight=0` 缓解
6. **强依赖 git master 的 Perth** → 构建可复现性风险
7. 高 `exaggeration` 会加快语速，需配低 `cfg_weight` 补偿

- **PyPI**：`neutts` **1.4.1**（2026-07-22）

| 型号 | 活跃参数 | 含嵌入总参数 | 语言 | HF createdAt |
|---|---|---|---|---|
| **NeuTTS-Air** | ~360M | ~552M | 英语 | **2025-09-15** |

### 2.2 能力

| 能力 | 结论 |
|---|---|
| 零样本克隆（TTS） | ✅ 支持，**最少 3 秒音频**（README） |

| 声音设计 | ❌ 不支持 |

**Apple Silicon（MPS）支持：✅ 支持（走 Metal / Apple Accelerate / ONNX-MPS 三条路）**

- README 专门给 **macOS Apple Silicon** 的编译指令：

### 8.4 许可证（★ 已核实 —— GPL-3.0，copyleft 是该模型最大的商业障碍）

- **GitHub `LICENSE` / HF API**：**GNU General Public License v3.0（GPL-3.0）**（GitHub API `license.spdx_id = "GPL-3.0"`；HF 模型卡 `license: gpl-3.0`）
- **逐条结论**：
  - ✅ **商用允许**（GPL-3.0 不禁止商业使用）
  - ⚠️⚠️ **但内嵌进闭源商业桌面 App：实质上不允许**。GPL-3.0 是**强传染性 copyleft**：
    - 如果你分发（distribute）包含 Seed-VC 的软件，**整个作品必须以 GPL-3.0 分发并提供完整源代码**

    - **闭源商业桌面 App 内嵌 = 必须开源你的整个 App**

  - ℹ️ 需随附许可证与源码
- ⚠️ **附加风险**：仓库**已归档**，即使拿到授权也无维护

### 10.8 Vevo（Wonderfy / Amphion）

- **四个预训练模型**：

### 10.9 MegaTTS 3（ByteDance）★ 值得关注

### 12.1 「代码宽松 / 权重限制」的陷阱清单（★ 本报告最重要的发现）

| **OuteTTS** | Apache-2.0 | **1.0-1B / 0.2 / 0.3 = CC-BY-NC(-SA)-4.0；1.0-0.6B = Apache-2.0** | ⚠️⚠️ 主力模型非商用 |

| **NeuTTS** | NeuTTS Open License | **Air = Apache-2.0；Nano/2E = NeuTTS Open License** | ⚠️ 同仓库两种许可 |
| **IndexTTS2** | bilibili Model Use License | 同 | ⚠️ 门槛 + 「不得改进其他 AI 模型」 |

### 12.3 特别提醒：GPL-3.0（Seed-VC）的实务含义

> **GPL-3.0 与「商业使用」的关系常被误解**：
> - GPL-3.0 **不禁止**商业使用 —— 你可以卖软件
> - 但 GPL-3.0 **要求**：一旦你**分发**（distribute）了包含 GPL 代码的作品，**整个作品必须以 GPL-3.0 许可并附带完整源代码**
> - **把 Seed-VC 二进制打进你的闭源商业桌面 App 并分发给用户 = 触发该义务 = 你必须开源你的整个 App**
> - ✅ **规避路径 1（推荐）**：只在**服务端**部署（GPL-3.0 **没有** AGPL 那样的网络服务条款），客户端通过 API 调用 → 不构成 distribute
> - ✅ **规避路径 2**：把 Seed-VC 作为**独立可执行文件 + 命令行调用**（法律上仍有争议，因为可能被认定为单一作品；风险自负）
> - ⚠️ **规避路径 3**：联系作者买商业授权 ——**未核实**是否存在此选项；且仓库已归档，作者可能已不响应

### 12.4 PerTh 水印（Chatterbox）的合规意义

Resemble AI 的 V3 博客明确指出水印动机来自监管：
- **EU AI Act 第 50 条**：要求 AI 生成音频自 **2026 年 8 月**起以机器可读方式标注
- **美国 TAKE IT DOWN Act**：对合成媒体提出内容可追溯要求

> **对本项目的含义（双面）**：
> - ✅ **资产**：Chatterbox 输出默认带 PerTh 水印，天然满足机器可读标注要求；检测库 `perth` 宽松开源，任何人可验证
> - ⚠️ **约束**：你**不能**宣称输出「无痕迹」；且水印「survive MP3 compression, audio editing, and common manipulations」（抗 MP3 压缩、音频编辑、常见处理）
> - ⚠️ 若你的产品需要无水印输出（例如某些创意场景），需自行改造 pipeline —— MIT 许可**允许**你这么做，但需自行承担合规责任
