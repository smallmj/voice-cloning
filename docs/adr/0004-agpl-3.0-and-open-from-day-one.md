# 采用 AGPL-3.0，并从第一个 commit 起公开

项目以 AGPL-3.0 授权，且从最初就公开，而不是等做完再开源。

**为什么不是宽松许可**：本赛道最直接的竞品 `jamiepine/voicebox` 采用 MIT（★53,981，创建于 2026-01）。若本项目也用 MIT/Apache-2.0，等于把工作无偿交给它可以闭源吸收；AGPL 则要求任何分发、或通过网络提供本软件的一方公开源码。当前分发策略是私下分发 / 公开仓库（不做境内推广、不上架应用商店），所以 AGPL 的「网络服务」条款很少被触发，代价可控。

**附带收益**：本项目最贵、最枯燥的组件是逐引擎适配层（每家厂商的鉴权、参数、错误码、音色生命周期各不相同）。现成的同许可实现 `debpalash/VoiceStudio`（AGPL-3.0，16 个引擎 + 能力矩阵）在许可上与本项目兼容，使参考与移植成为可能。

**代价（须认清）**：一旦参考了 AGPL 代码，本项目在事实上锁死在 AGPL；将来若想提供闭源商业版本，需要持有全部版权（自己独立开发则天然满足，但引入外部贡献者后需要 CLA）。
