## 一、硅基流动 SiliconFlow

### 1.1 产品 / 模型 / API

**国内站 apisiliconflow.cn 与海外站 siliconflow.com 的可用模型不同，这是本次最重要的发现之一。**

| 站点 | 定价页实际列出的 TTS 模型（已 grep HTML 核实） |
|---|---|
| **www.siliconflow.cn / pricing（国内）** | 仅 `fnlp/MOSS-TTSD-v0.5`、`FunAudioLLM/CosyVoice2-0.5B`（另有免费 ASR：SenseVoiceSmall、Qwen3-ASR-1.7B、星辰 ASR 系列） |
| **www.siliconflow.com / zh/pricing（海外）** | `fishaudio/fish-speech-1.5`、`FunAudioLLM/CosyVoice2-0.5B`、`IndexTTS-2` |

- **未核实**：Kokoro 是否在 SiliconFlow 提供。国内/海外两个定价页的 HTML 中均未出现 Kokoro 字符串；文档 `llms.txt` 索引中也没有 Kokoro 页面 → 以本次核实为准，**SiliconFlow 未提供 Kokoro**。
- 用户提问中的「托管的 CosyVoice2、IndexTTS-2、Fish-Speech-1.5、MOSS-TTSD、Kokoro」需修正为：**MOSS-TTSD + CosyVoice2 在国内站；再加 Fish-Speech-1.5 + IndexTTS-2 在海外站；Kokoro 未见。**

**API**：
- 端点 `POST /v1/audio/speech`（OpenAI 兼容风格），`POST /v1/uploads/audio/voice`（上传音色），`GET /v1/audio/voice/list`，`POST /v1/audio/voice/deletions`
- 官方文档明确给出 OpenAI Python SDK 用法：`OpenAI(base_url="https://api.siliconflow.com/v1")` → **OpenAI 兼容** （[TTS 文档](https://docs.siliconflow.com/cn/userguide/capabilities/text-to-speech)）
- 模型广场的「语音」筛选标签即为当前可用模型列表（官方文档注：支持的 TTS 模型可能调整）

**请求参数（create-speech，已核实）**：`model` / `input`（长度 **1–128000**）/ `voice` / `response_format`（mp3、opus、wav、pcm，默认 mp3）/ `sample_rate` / `stream`（默认 true）/ `speed`（0.25–4.0，默认 1）/ `gain`（-10–10 dB，默认 0）。响应为**音频二进制**（非 JSON、非 URL）。

### 1.2 能做什么

| 能力 | 核实结果 |
|---|---|
| zero-shot 复刻 | **有**，通过 `/v1/uploads/audio/voice` 上传参考音频，返回 `uri` 作为 `voice` 参数 |
| few-shot 微调 | 官方文档未提供面向用户的微调接口（**未核实**是否有定制微调服务） |
| 音色设计（文字描述生成音色） | **未见**该能力 |
| 多语言 | Fish-Speech-1.5：中、英、日、德、法、西、韩、阿、俄、荷、意、波、葡；CosyVoice2：中、英、日、韩 + 中国方言（粤语、四川话、上海话、郑州话、长沙话、天津话） |
| 情感控制 | CosyVoice2 支持快乐/兴奋/悲伤/愤怒等；通过富文本或自然语言细粒度控制。官方示例使用 `<|endofprompt|>` 分隔指令与正文 |
| 语速/停顿/SSML | 仅 `speed` 参数（0.25–4.0）。**未见 SSML** |
| 流式 | 有（`stream` 默认 true） |
| 长文本上限 | `input` 1–128000（按字符计。实际可用性受计费与超时影响，**未核实**官方是否另有字数建议） |

### 1.3 复刻参考音频要求（已核实原文）

- 上传接口需同时提供：`model`、`customName`、`text`（参考音频对应的文字内容）、音频（base64 `data:audio/mpeg;base64,...` **或** multipart 文件）
- 文档正文：「参考音频要小于 **30s**」
- 最佳实践：「建议时间 **8～10s** 左右」
- 质量要求：仅限单一说话人；吐字清晰、音量/音调/情绪稳定；停顿建议 0.5s；无背景噪音、无房间回声
- 支持格式：mp3、wav、pcm、opus；推荐 192kbps 以上 mp3
- 条数上限、文件大小上限：**未核实**

- 第三方社区测评（如 tts.ai 的 community rating：CosyVoice 2 ≈ 4.26/5，IndexTTS-2 ≈ 3.91/5）为**非权威聚合站**，仅供参考，不建议作为采购依据

REST（`/v1/audio/speech`）+ OpenAI 兼容 SDK；返回二进制音频；格式 mp3 / opus / wav / pcm。是否 WebSocket：**未核实**（TTS 文档未提及）。

- 采样率：**未核实**

响应 `VoiceCloneResponse`：`voice`（音色 ID）、`file_id`（试听音频文件 ID）、`file_purpose`（固定 `voice-clone-output`）、`request_id`。

### 3.2 能做什么

## 九、对「第三方桌面软件」选型的落地建议（基于已核实事实）

1. **最省事、成本最低的复刻**：智谱 GLM-TTS-Clone（6 元/次，3 秒样本，10M 文件）+ GLM-TTS（2 元/万字符）。有内容安全审核（错误码 1301），需处理拦截分支。
2. **成本最低的音色克隆单价**：PPIO Fish Audio Voice Clone ¥0.7/音色（但 PPIO 的合规条款与 SLA 未核实，需商务确认）。
3. **音色表现力/音色设计最强**：Fish Audio（唯一提供 `voice-design-1` 文字生成音色 + 83 语言 + WebSocket），付费即获商用许可——但**上传内容会被用于训练**，且 API Key 不得转让。
4. **表演控制最强（无需真音色即可做出表演感）**：StepFun `instruction` + 括号内联指令——如果桌面软件只需要「演文本」而非「造音色」，这是最优雅的接口设计。
5. **⚠️ 转售/白标合规红线**：**硅基流动条款明文禁止转售、禁止为他人利益使用资源、禁止使第三方能够使用服务**（海外站还限制许可「仅限于在新加坡使用」）。若做白标或内置平台 Key 代调用，硅基流动是本次调研中风险最高的一家；Fish Audio 也禁止 API Key 未经同意买卖转让。**统一推荐「用户自备 Key」模式**。
6. **⚠️ 开源权重许可**：若自托管，**Fish-Speech 必须单独取得 Fish Audio 商用授权**（研究许可明确排除商用，且明确覆盖 "hosted service or API"）；**IndexTTS-2 使用 bilibili 自定义许可**，中小规模可免费商用，但 MAU > 1 亿或年收入 > 1 亿人民币需申请，且必须保留版权声明、不得用输出改进其他 AI 模型、不得使用 bilibili 商标。**CosyVoice / GPT-SoVITS / Kokoro / MOSS-TTSD 均为标准宽松许可（Apache-2.0 / MIT / Apache-2.0 / Apache-2.0），商用无障碍。**
