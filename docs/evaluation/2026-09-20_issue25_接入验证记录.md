## 过程中的发现（均已修复 / 固化）

1. **安装器重试完整性缺陷**：失败步骤擦除自身 artifact 后，先前已完成的
   同 artifact 步骤（如与 engine 共享 venv 的 torch）仍标 completed，重试
   会产出没有 torch 的 venv。已在 `installer.run_install` 加预清理遍：
   擦除时把共享同 artifact 的已完成步骤一并重置为 pending。
2. **FireRedTTS3 网络不可达的播种路径**：本机到 GitHub / HF 全部被墙，
   仅 ModelScope 可用。新增 `VOICECLONE_FIREREDTTS3_LOCAL_UPSTREAM`
   （本地已打补丁的 checkout 播种 engine 步）与
   `VOICECLONE_FIREREDTTS3_LOCAL_WEIGHTS`（本地 PoC 权重播种 weights 步），
   与 IndexTTS-2.5 MPS 的本地权重复用同一先例。
3. **VoxCPM2 参考文本三种模式**在真机逐条验证：有转写 → Hi-Fi（最高
   相似度）+ reference tokens；无转写 → 纯音色 reference 模式（均实测出声）。
4. **dots.tts 归一化依赖核实**：官方 pyproject 硬依赖 WeTextProcessing
   （pynini 族），plan §5 疑云核实为真——证据与接入对策见
   `docs/research/CORRECTIONS.md` C-003 与 NOTICE.md §3。
