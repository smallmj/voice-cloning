1. **情感自然度**公认最好的是 `IndexTTS2` 与 `MiniMax`（两者「不出戏」）；
2. **多音字可控性**只有 `IndexTTS2`（字符+拼音混合）与 `CosyVoice3`（拼音修补）有**正式纠错机制**，其余靠手动注音——**这是做字幕/播报型桌面软件的硬指标**；
3. **长文本情绪连贯性目前没有任何方案完全解决**，业内共识是「长内容要分段跑 + 人工兜韵律」。

### 6.4 评价方法提醒

- **seed-tts-eval**（字节跳动 2024 提出）是**客观基准**（WER/CER + 说话人相似度 SIM），适合比复刻保真度，但**不反映情感/韵律等主观质量**。
- **TTS Arena**（HuggingFace `TTS-AGI/TTS-Arena-V2`）与 **Artificial Analysis Speech Arena** 是**众包主观盲听**，更贴近「好不好听」，但投票样本偏向英文。
- **各厂商官方文档中未核实到公开 MOS 数值**；厂商宣传的 WER/CER/ELO 多为自述，需谨慎引用。
- 采购前**强烈建议自行做 A/B 盲测**（用自己业务的真实文本 + 真实参考音频），不要依赖任何单一榜单。

## 8. 推荐排序（S / A / B）

**分档依据**：① 效果（榜单 + 复刻保真）② 稳定性（并发/限速/文档成熟度）③ 价格 ④ 接入难度 ⑤ **合规（转售/白标条款）**。合规是硬门槛——条款越硬，档位越低。

### 🥇 S 档（推荐作为第三方桌面软件的主力后端）

| 厂商 | 理由 |
| --- | --- |
| **阶跃星辰 StepFun** | 兼顾三点：**效果强**（AA 榜第 7，中国大陆第二）、**价格极低**（`step-tts-mini` 0.9 元/万字符、`stepaudio-3-tts` 2.5 元）、**复刻便宜**（9.9 元/音色）、接口形态接近 OpenAI（`/v1/audio/speech` + WebSocket）。**未检索到转售禁止条款**。限制：单次 1000 字符、复刻音频需 5–10s。 |
| **智谱 AI** | **复刻成本最低（6 元/次）**、合成便宜（2 元/万字符）、**seed-tts-eval 中文 CER 第一（0.89）**、有内容安全审核（合规上更安全）。需签《模型商用许可协议》。 |

## 10. 一句话选型建议

- **要合规最稳 + 效果最好** → 让用户**自备 Key**，主后端选 **阿里云百炼 CosyVoice/Qwen-TTS**（AA 第 4、0.8 元/万字符、复刻 0.01 元）。
- **要便宜且条款松** → **阶跃星辰 StepFun**（0.9–2.5 元/万字符、复刻 9.9 元、无明确转售禁令）+ **智谱 GLM-TTS**（2 元/万字符、复刻 6 元/次）。
- **要功能最全（复刻 + 文字造音色 + 40 语 + 长文本）** → **MiniMax**（BYOK 模式）。
- **要极低合成单价（大批量有声内容）** → **腾讯云基础版**（0.15–0.21 元/万字符，代价是 2500–4500 元/音色 + 10–20 分钟语料）。
- **要图片/文字描述生成音色** → **火山引擎音色设计**（支持图片 prompt）或 **Fish Audio `voice-design-1`**（$0.01/次）；**商汤 SenseAudio** 也有文生音色但**不能在软件里通过 API 发起**。
- **要最省事的价格透明二线备选** → **有道智云**（10 元/音色 + 2 元/万字符）或 **华为云 SIS**（5 秒零样本，但限华东-上海一 + 单账号 1000 音色）。
- **需要 26 种情感 + 5 种方言 + 拼音纠错 + SSML** → **科大讯飞一句话复刻多风格版**（注意其条款禁止转售，只能 BYOK）。
- **绝对不要**在没有书面授权的情况下，把**火山引擎豆包语音**、**阿里云百炼**或**科大讯飞**的 Key 内置进第三方软件统一代调用。
