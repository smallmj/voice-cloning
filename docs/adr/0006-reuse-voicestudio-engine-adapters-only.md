# 复用 VoiceStudio 的单引擎适配层，但不复用它的数据模型与 UI

本项目与 `debpalash/VoiceStudio` 同为 AGPL-3.0，因此参考与移植它的代码在许可上兼容。范围被刻意限定：**只取「单个引擎怎么调」这一层**（鉴权、参数、错误码、音色生命周期、能力声明），**不取它的数据模型与界面**。

**为什么只取一半**：适配层里装的是无法推导、只能靠踩坑得来事实——火山要求 wav 且 ≤10MB、MiniMax 音色 7 天未调用即删除、阿里「1 个汉字计 2 个字符」、讯飞长文本结果云端只存 7 天。这些是纯收益。而它的 profile 抽象**绑死单一引擎**，与本项目 ADR-0001（音色是引擎无关的逻辑实体）方向相反，抄过来反而要推翻。

**已知代价**：引入对一个**正在从 Tauri 重写到 Electron** 的仓库的耦合，其代码结构处于流动状态，不能假定 API 稳定。因此移植的是事实与算法，不是模块依赖——不把它作为 Git submodule 或包依赖引入。

**义务**：AGPL-3.0 要求标注来源。凡移植了代码的位置需在仓库的 `NOTICE` / 第三方清单中注明出处与许可证，这是许可证义务，不是礼貌。
