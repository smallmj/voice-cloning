## 关键结论速览（决策视角）

1. **中文 + 商用授权都干净的组合（首选）**：**CosyVoice 2 / Fun-CosyVoice 3（Apache-2.0）**、**Qwen3-TTS（Apache-2.0）**、**Chatterbox Multilingual（MIT）**、**MOSS-TTSD（Apache-2.0）**、**SparkTTS（Apache-2.0）**、**MegaTTS3（Apache-2.0，但 encoder 未放）**、**Kani-TTS（Apache-2.0）**。
2. **中文强但授权有坑**：**F5-TTS**（权重 CC-BY-NC 非商用）、**IndexTTS 2**（bilibili 自定义协议，商用需联系）、**XTTS-v2**（CPML 且已无法购买商用授权）、**Fish/OpenAudio S1-mini**（CC-BY-NC-SA）、**GPT-SoVITS**（MIT 可商用，但声音数据授权自担）。
3. **托管 API 最便宜的中文方案**：SiliconFlow 的 **CosyVoice2-0.5B / IndexTTS-2 ¥0.05/千字符**；DeepInfra 的 **Kokoro $0.62/1M 字符**（但中文质量仅 D 级）。
4. **托管 API 中文质量优先**：**Baseten Qwen3-TTS $3/1M 字符**（性价比突出）、**Boson Higgs TTS 3 $15/1M 字符**、**MiniMax speech-2.8-turbo $60/M 字符**、**阿里百炼 cosyvoice-v3-plus 2 元/万字符**。
5. **Groq / Together / Fireworks 对中文支持有限或不明**：Groq TTS 仅英/阿双语；Together 的 Orpheus 为英文、Kokoro 中文质量低；Fireworks 的 TTS 模型与价格**未能核实**。
6. **想自建**：Modal（H100 $0.001097/s）与 Baseten 提供按秒 GPU；Replicate 按硬件秒计费（L40S 上 Chatterbox 多语版单次 ≈$0.0046）；fal/DeepInfra/SiliconFlow/Novita 则直接按字符/字节托管开源权重。

## 未核实项汇总（明确列出）

- Groq TTS 各模型的**具体速率限制数值**（RPM/RPD/ASH/ASD）——官方要求登录 Console 查看。
- Fireworks AI 的 **TTS 模型清单与按字符价格**（来源互相矛盾）。
- Together AI 的 **Inkling** 是否为 TTS 模型及其 $1/1M 字符口径。
- Together AI Rime Mist v2/v3、Rime Arcana v2 的价格。
- fal.ai / Novita / DeepInfra 的 **MiniMax Speech 2.8** 单价。
- **MiniMax Speech 是否开源权重**（HF 组织下有 2B Text-to-Audio 模型，未确认对应关系）。
- **Higgs Audio v3 的授权协议**；**Higgs Audio v2 中文 MOS**。
- Step-Audio 2 mini、Kimi-Audio、Qwen2.5-Omni、VibeVoice、Kani-TTS、Zonos、Dia 的**托管 API 与价格**。
- Zonos v0.1 的**中文支持**；Dia 的多语支持。
- GPT-SoVITS 的第三方托管 API（LMSpeed 列出的 $75/M 未验证供应商可信度）。
- Cartesia credit 到美元的换算。
- 多数模型的**显存需求**（仅 F5-TTS 6–16GB、GPT-SoVITS ≥6GB、XTTS-v2 3–5GB 有来源）。
